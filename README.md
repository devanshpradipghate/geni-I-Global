# NeonVerse Global (geni-I-Global)

A neon-styled global social communication app prototype inspired by Yeetalk and rebuilt around:

- expressive interactive profiles,
- gamified coin rewards,
- animated avatar customization,
- inbox messaging + calling,
- multiplayer social games,
- VIP-tiered experiences.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Included feature slices

- **Interactive profiles** with animated country badges, tap-trigger mood effects, and level aura.
- **15 neon animated avatar frames** with coin purchase logic for non‑VIP users and full VIP unlocks.
- **VIP animated banners** (Neon Pulse, Galaxy Wave, Electric Crown, Fire/Ice, Prestige Gradient).
- **Coin reward system** from daily login, tasks, events, games, and referrals, plus redemption surfaces.
- **Messaging + call UX** with voice for all, video-gated for VIP, and in-chat call settings.
- **Game hub** for Chess/Billiard/Carrom and VIP-only roleplay room access notes.
- **VIP pricing model**: 2 months free, then $2/4 months, $18/8 months, $50/12 months.
- **Neon Light/Dark themes**, moderation/security/scalability architecture indicators.

> Animated gift exchange flows are intentionally omitted per product requirement.
